# BugHunter — система учёта и отслеживания дефектов

## 1. Назначение и функциональные возможности
**BugHunter** — лёгкое веб-приложение класса Bug Tracking System для регистрации, классификации, распределения и контроля жизненного цикла дефектов программного обеспечения в рамках проектов разработки.

**Основные функциональные возможности:**
* **Аутентификация и ролевая модель:** регистрация пользователей, безопасный вход (`password_hash` / `password_verify`), разграничение прав доступа (`Администратор`, `Разработчик`, `Тестировщик`).
* **Аналитический дашборд:** общая сводка по статусам и критическим дефектам (`COUNT`, `SUM CASE WHEN`), статистика по проектам, нагрузка на исполнителей и распределение по приоритетам (`GROUP BY`, `LEFT JOIN`).
* **Управление проектами:** создание, просмотр, редактирование и удаление проектов с уникальным кодом, регистронезависимый поиск с `LIKE` и пагинация.
* **Полный жизненный цикл дефектов:** регистрация багов (описание, шаги воспроизведения, ожидаемый и фактический результат), управление статусами и приоритетами, назначение исполнителя, поиск с `LIKE`, фильтрация и постраничная навигация.
* **Комментарии и аудит изменений:** добавление и удаление комментариев к дефектам, автоматическое журналирование всех изменений полей дефекта в таблицу `BugHistory`.
* **Информационная безопасность:** защита от SQL-инъекций (подготовленные выражения PDO), CSRF-токенов (`hash_equals`), XSS (`htmlspecialchars`) и IDOR.

## 2. Требования к окружению
* **Операционная система:** Windows 10/11, Linux (Ubuntu 20.04+), macOS
* **Интерпретатор PHP:** версия `8.0` или выше
* **Обязательные расширения PHP:**
  * `pdo_sqlite` — взаимодействие с СУБД SQLite 3
  * `mbstring` — валидация многобайтовых строк UTF-8 и регистронезависимый поиск кириллицы
  * `session` — управление сессиями и CSRF-токенами
* **СУБД:** SQLite 3 (локальный файл `database/bughunter.db`)
* **Веб-сервер:** встроенный сервер PHP (`php -S`), Apache 2.4+ или Nginx

## 3. Инструкция установки и запуска

1. **Распакуйте или клонируйте проект** в рабочую директорию:
   ```bash
   cd /path/to/bughunter
   ```

2. **Проверьте конфигурацию PHP и права доступа:**
   * Убедитесь, что в `php.ini` включены расширения `pdo_sqlite` и `mbstring`.
   * Убедитесь, что каталог `database/` и файл `database/bughunter.db` доступны на чтение и запись для веб-сервера. При первом подключении приложение автоматически проверит и обновит структуру таблицы `Bugs`.

3. **Запустите встроенный веб-сервер PHP**, указав корневой директорией папку `public`:
   ```bash
   php -S localhost:8000 -t public
   ```
   > **Важно:** Запуск без флага `-t public` приведёт к ошибкам маршрутизации `404 Not Found`.

4. **Откройте приложение в браузере:**
   Перейдите по адресу `http://localhost:8000/`. После входа откроется аналитический дашборд (`dashboard.php`).

## 5. Инструкция резервного копирования и восстановления

### Создание резервной копии
* **Linux / macOS / Git Bash:**
  ```bash
  mkdir -p backups
  sqlite3 database/bughunter.db ".backup 'backups/bughunter_$(date +%Y%m%d_%H%M%S).db'"
  ```
* **Windows PowerShell:**
  ```powershell
  New-Item -ItemType Directory -Force -Path backups
  Copy-Item "database\bughunter.db" -Destination "backups\bughunter_$(Get-Date -Format 'yyyyMMdd_HHmmss').db"
  ```

### Восстановление из резервной копии
1. Остановите веб-сервер (`Ctrl + C`).
2. Замените рабочий файл базы данных копией:
   ```bash
   cp backups/bughunter_YYYYMMDD_HHMMSS.db database/bughunter.db
   ```
3. Запустите веб-сервер повторно.
